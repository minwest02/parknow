## 1. 프로젝트 목적

도심 목적지 근처 공영주차장을 찾아갔는데 만차라서 주변을 2~3회 돌며 시간을 버리는 문제를 해결합니다.
(03 제안서) 6주 안에 도심 방문 운전자의 **주차 탐색 소요 시간을 평균 16.5분에서 6분 이내로** 줄이고, 프로토타입 사용성 점수(SUS) 75점 이상을 목표로 합니다.

| 구분 | 내용 |
|---|---|
| 대상 사용자 | 도심 번화가·주택가 밀집 지역을 방문하는 자차 운전자(특히 2030 초보·주말 운전자) |
| 핵심 문제 | ① 출발 전 자리 유무를 몰라 거리·익숙함으로 주차장을 고름 ② 만차 후 재검색해도 같은 정보(거리·요금)만 보여 복구하지 못하고, 요금을 모른 채 민영주차장에 들어감 |
| 근거 | 03 제안서 문제 근거(E01~E03), 05 맥락질의·06 작업분석의 As-is 마찰 지점 |

## 2. 사용자 요구사항과 구현 기능 대응

| 요구사항(06 워크북) | 구현 기능 | 확인 방법 |
|---|---|---|
| R1. 출발 전 주차장 후보별로 자리가 있을 가능성(잔여면 상태)과 갱신 시각을 확인하고 고를 수 있어야 한다 | 목적지 검색 → 반경 500m 지도 + 카드 목록. 잔여면을 **신호등 3단계(● 여유 / ▲ 보통 / ■ 만차)**로 색·모양·글자 함께 표시. 카드 정보 위계: 잔여면 상태 → 도보 거리 → 요금, 갱신 시각 표시 | 홍대입구역 검색 후 카드·지도 확인 |
| R2. 만차일 때 재검색 없이 대체 1순위 주차장을 확인하고 바로 경로를 연결할 수 있어야 한다 | 안내 중인 주차장이 만차가 되면 **만차 알림 + 대체 추천 1순위 카드**(잔여면·도보 거리·요금·추천 이유) 표시, 한 번의 탭으로 안내 변경 | 안내 시작 후 '만차 상황 만들기' 버튼 |
| R3. 시간 압박이 있을 때도 요금·도보 거리를 알고 결정할 수 있어야 한다 | 모든 카드·알림에 30분 요금과 도보 시간 표시, 추천순·가까운순·저렴한순 정렬 | 정렬 탭 전환 |

## 3. 주요 기능

1. **목적지 검색**: 검색어 자동완성, 인기 목적지 바로가기(시연 데이터 5곳), 지원하지 않는 지역은 안내 메시지
2. **반경 500m 주차장 지도**: 목적지 핀과 주차장 표지(P)를 상태 색으로 표시, 남은 면수 표시, 표지를 눌러 상세 보기
3. **주차장 카드 목록과 정렬**: 추천순(자리 상태 → 거리), 가까운순, 저렴한순 / 추천 1순위 배지
4. **상세 정보**: 남은 면수(큰 숫자), 상태, 도보 시간, 30분 요금, 운영 시간, 갱신 시각. 이미 만차면 대체 주차장 바로 제안
5. **안내 모드와 실시간 감시**: 선택한 주차장의 상태를 계속 확인, 카카오맵 길찾기·T맵 앱으로 이어서 안내(외부 내비 연결)
6. **만차 시 대체 추천**: 자리 상태·도보 거리·요금 점수로 1순위를 골라 추천 이유와 함께 제시, '다른 후보 보기'·'그래도 계속 가기' 선택 가능
7. **운전 안전 안내**: "운전 중에는 조작하지 마세요", 만차 알림에 "정차 후 선택" 안내, 큰 버튼(최소 44px), 색에만 의존하지 않는 상태 표시
8. **시연·평가 도구(데스크톱 왼쪽 / 모바일 하단)**: 잔여면 10초 주기 갱신 시뮬레이션, 만차 상황 만들기 버튼, **UT 타이머**(첫 검색부터 안내 시작까지 걸린 시간과 단계 기록, 목표 6분)

## 4. 범위

| 포함 | 제외(03 제안서 기준) |
|---|---|
| 목적지 검색, 반경 내 공영주차장 지도·목록, 잔여면 신호등 표시, 만차 시 대체 추천, 외부 내비 연결 | 주차 요금 결제·예약, 자체 음성 내비게이션, 관리자용 관제 화면, 필터(경차·전기차)·다크모드 전용 디자인 |

**데이터 안내:** 주차장 이름·위치·잔여면·요금은 **시연용 가상 데이터**입니다. 브라우저에서 바로 실행되도록 잔여면 변화를 시뮬레이션했으며, 실제 서비스에서는 공공데이터포털(data.go.kr)의 실시간 주차정보 API로 바꿔 연결합니다.

- 가장 간단한 방법: `index.html`을 내려받아 크롬·엣지 등 브라우저로 엽니다(인터넷 연결 시 글꼴까지 적용).
- 휴대폰 화면 확인: 크롬 개발자 도구(F12) → 기기 툴바(Ctrl+Shift+M) → iPhone 등 선택. 화면 폭 900px 이하에서는 앱 화면이 전체 화면으로 바뀝니다.

## 6. GitHub 저장소와 배포(GitHub Pages)

1. GitHub에서 새 저장소 생성(예: `parknow`, Public)
2. `index.html`, `README.md`, `PROMPTS.md`를 업로드(Add file → Upload files → Commit)
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
4. 1~2분 뒤 `https://<GitHub아이디>.github.io/parknow/` 접속해 작동 확인 후 이 문서 맨 위에 링크 기입
